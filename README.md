# OT-pratice

这是一个golang-OT算法练习仓库，后端代码手敲，前端代码靠天才程序员Deepseek

# 运行

本仓库涵盖后端和前端，拉取代码后可直接运行

```bash
git clone https://github.com/Bluore/OT-practice
cd OT-practice
go run ./cmd
```
